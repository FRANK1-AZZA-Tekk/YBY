# Prompts-base dos agentes YBY

Estes prompts definem a persona, responsabilidade, ferramentas, limites e formato de saída de cada agente do ecossistema YBY.

## Agentes

1. `orchestrator.md` — coordenador central
2. `archivist.md` — memória e recuperação de conhecimento
3. `technician.md` — hardware, firmware e energia
4. `researcher.md` — pesquisa externa e fontes
5. `builder.md` — programação, testes e firmware
6. `operator.md` — Calendar, Gmail, arquivos e automações
7. `guardian.md` — segurança, permissões e auditoria

## Regra global

Nenhum agente deve executar ações externas, financeiras ou irreversíveis sem aprovação humana explícita.
